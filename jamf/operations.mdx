## Hygiene

- Remove or disable unused Jamf accounts called out in March: leftover tool-named logins, API reader, Bob Jones.
- Enrollment account: **Enrollment Only**, not Administrator.
- Jamf Pro password policy: more than "6-month max age." Match [Passwords and MFA](/sops/password-mfa).
- Kill Catalina-era policies and unused Restricted Software entries.
- Split ScreenConnect into deploy-once vs Self Service reinstall.
- Disable "Include home directory sizes" unless you actually report on it.
- Audit scripts. Most were test leftovers.
