<Note>
  IT-only. This is the handoff for a **new local Cursor agent** on a Mac that already has the read-only Jamf MCP. Do not paste Client Secret, enrollment passwords, or FileVault personal recovery keys into that chat.
</Note>

This Cloud Agent cannot see the live tenant. The dedicated Jamf agent must run **locally** (or in a Cloud environment where the same MCP is installed). Connector steps: [Connect Cursor](/jamf/connect-cursor). Fleet context: [Why Jamf is an island](/jamf/overview). Punch-list: [Operations](/jamf/operations).

## Before you start the agent

1. Jamf Pro API Role `Cursor read` — **Read** only. No Create / Update / Delete. No **View Disk Encryption Recovery Key**.
2. API Client `Cursor JamfMCP` assigned that role. Secret in 1Password or Cursor MCP settings, never Slack.
3. Community [JamfMCP](https://github.com/liquidz00/jamfmcp) pointed at `https://intertrend.jamfcloud.com` via `jamfmcp-cli -p cursor`.
4. Cursor → Settings → Tools & MCP shows the tenant server connected (not just `developer.jamf.com/mcp`).
5. Start a **new** local agent. Paste the brief below as the first message.

Official Jamf MCP at `https://developer.jamf.com/mcp` is **docs only**. If the agent only has that, it cannot list Intertrend Macs.

## Day-one questions (prove the pipe)

The agent should answer these from the tenant, not from this page:

1. Computers with last check-in older than 14 days.
2. FileVault counts: enabled / deferred / unknown. Do **not** retrieve personal recovery keys.
3. macOS version histogram. Flag Ventura and older.
4. Policies and configuration profiles scoped to **All Computers**.
5. Delta vs the [March 2026 operations punch-list](/jamf/operations): which gaps look already closed.

If those five come back from Jamf, the island is open. Then stop and wait. Writes are a later slice.

## After the five answers

Tate decides the next slice. Likely order:

1. Hygiene from [Operations](/jamf/operations) that the tenant confirms is still open.
2. Protect stale-record list and whether telemetry is reaching KMicro.
3. A **separate** write role, disabled, test Smart Group, human-confirmed payload. Not All Computers.

## If the agent cannot see Jamf

The MCP is not in that session. Fix the connector. Do not have the agent scrape screenshots or guess from the March PDF.
