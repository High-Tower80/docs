<Warning>
  Do **not** click links, open attachments, or reply. If you already did, tell IT immediately.
</Warning>

This page is for **everyone**. If you are on IT and need the full triage playbook, see [IT phishing triage](/sops/phishing-triage).

## Fastest report

In Slack, run `/assist` (or `/halp`, `/helpdesk`, `/support`). Attach the **original** message so headers stay intact. Do not forward a stripped copy.

- **Gmail:** More (three dots) → Download message (`.eml`), then attach that file in Slack. Or More → Forward as attachment, save it, and drop it on the Assist form.
- **Apple Mail:** Right-click the message → Forward as Attachment, save it, attach it in Slack.

Then mark it as phishing/junk in Gmail if you can: More → Report phishing.

Do not email a leftover helpdesk address. Slack is the ticket.

## Red flags

- Sender address or domain does not match the company name
- Urgent or threatening language
- Asks for passwords, MFA codes, or payment details
- Unexpected attachments or links
- Generic greeting such as “Dear Customer”

## After you report

1. Wait for IT. Follow any extra steps they send (password reset, extra checks).
2. If you think credentials or files were already exposed, say so in the ticket.
3. Stay current on company security training when it is assigned.
