How people request, receive, and track hardware. Standard and retirement rules: [Endpoint security](/policies/endpoint-security).

**Tools:** Assist (Slack), asset inventory, Jamf Pro.

## Standard issue

- **Laptop:** Apple Silicon MacBook Air or Pro (current M-series). FileVault escrowed to Jamf before it leaves IT.
- **Not standard:** Intel Macs, personal machines as a daily driver, Windows PCs. Endpoint protection is Jamf Protect only.
- Monitors, docks, and desks may need manager or Finance approval.

If someone asks to keep a 2015–2019 Intel box "because it still works," that is a retirement conversation, not a preference.

## Procedure

1. **Request** — `/assist`. Hardware type, why, ship-to if remote.
2. **Approval** — extras go through manager / Finance.
3. **Build** — IT assigns the asset, enrolls in Jamf (user-initiated today; ABM / ADE is the target, not live as of March 2026), installs required profiles, updates the tracker (user, serial, date).
4. **Delivery** — office pickup or tracked ship.

Do not write enrollment secrets into the ticket, Slack, or this site.

## Tips

- Update inventory on every reassignment. The sheet going stale is how we lose a Mac.
- Use `/assist` for every request so there is an audit trail.
- Confirm charger and, for remotes, a return label plan if they leave.

**Contact:** `/assist` in Slack.
